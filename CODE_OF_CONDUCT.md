# Code of Conduct

The `libcortlet-upgradesched` project follows the official Cortlet Code of Conduct.

All contributors, maintainers, reviewers, issue participants, and community members are expected to follow it when participating in this project.

Please read the full Code of Conduct here:

[https://www.cortlet.com/legal/code-of-conduct](https://www.cortlet.com/legal/code-of-conduct)

## Scope

The Cortlet Code of Conduct applies to participation in project spaces including:

- Repository issues
- Pull requests
- Code reviews
- Discussions
- Community channels
- Contributor interactions
- Other official Cortlet project spaces

## Reporting

If you experience or witness behavior that may violate the Code of Conduct, follow the reporting guidance provided in the official Cortlet Code of Conduct.

## Agreement

By participating in the `libcortlet-upgradesched` project, you agree to follow the Cortlet Code of Conduct.
